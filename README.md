# Allah · NOOR 온라인 기도원

개인 캐릭터와 양탄자를 꾸미고 세계의 유명 장소를 참고한 가상 광장에서 함께 머무는 3D 웹 메타버스입니다.

## 기능

- 캐릭터 유형·얼굴형·피부 톤·수염·이름·기도 복장·머리 덮개·양탄자 문양/색상 선택, 이 기기에 자동 저장
- 고해상도 대리석 결, 양탄자 직조/자수, 브러시드 골드, 푸른 타일, 환경 반사와 품질 설정
- 누르 대기도원 / 타지마할 광장: 하늘이 보이는 대형 야외 공간
- 맵당 3개 서버, 서버당 50개 연결, 실제 WebSocket 이동·외형·기도 자세 동기화
- 위치/도시/좌표로 하루 다섯 번 기도시간 계산. 나침반과 방향 센서는 사용하지 않으며 좌표는 서버로 전송하지 않음
- 건의사항·자유게시판: 서버 영구 저장, 목록/페이지/상세/글쓰기/본인 글 삭제, 연속 게시 제한
- 기기별 친구 코드, 친구 요청/수락/거절/해제, 현재 서버 채팅
- 기도 자세 순환과 방향 정렬
- 기본 소리: 퍼블릭 도메인 물소리 + 바람/실내 룸톤. 악기 없음
- 기도모드: **2시간 25분 10초 알바카라 낭송** 개인 스트리밍/반복. 기도 종료 시 멈추고 다음 기도에서 이어 듣기. 기도 중 자연음 끄기. 음량/음소거/개인 음원 선택
- 낭송은 CC0로 표시된 원본을 사용. 전체 꾸란 녹음으로 표시하지 않음. [음원과 라이선스](CREDITS.md)

## 언어

21개 언어의 화면/접근성/오류 안내 문자열을 제공합니다: 한국어, 영어, 아랍어, 우르두어, 인도네시아어, 벵골어, 튀르키예어, 페르시아어, 말레이어, 힌디어, 프랑스어, 하우사어, 스와힐리어, 파슈토어, 소말리어, 우즈베크어, 러시아어, 카자흐어, 아제르바이잔어, 타지크어, 중국어 간체. 첫 방문 기본 언어는 인도네시아어입니다. 첫 입장 화면과 상단 메뉴·설정에서 언어를 바로 선택하고 기기에 저장합니다. ?lang=ko처럼 지정한 언어와 직접 저장한 선택이 기본값보다 우선합니다. RTL은 아랍어/우르두어/페르시아어/파슈토어에 적용합니다. 게시판 글과 이용자 이름은 원문으로 유지합니다. 번역은 초기 초안이며 원어민 검수가 필요합니다.

## 기도 공간과 소통

기도모드에 들어가면 매트 전체와 앞쪽에 보이지 않는 통행 제한이 적용됩니다. 결제나 친구 여부와 관계없이 서버와 클라이언트에서 검사합니다. 기도 중에는 전체채팅·귓속말·인사가 전달되지 않으며, 종료 후 기존 채팅 설정으로 돌아갑니다. 억제된 대화는 재생하지 않습니다. 기도모드 하단에는 Quran.com 버튼이 나타납니다.

인사 버튼은 오른손을 가슴에 얹고 살짝 고개를 숙이는 동작과 ‘السلام عليكم’ 문구를 표시합니다. 기도 자세는 기도모드 전용입니다. 아바타는 맨발이며 걷는 손은 안쪽을 향해 살짝 쥡니다. 알라나 예언자 무함마드의 형상을 만들지 않습니다.

실제 결제는 비활성 상태입니다. 기기 쿠키 기반 계정은 쿠키를 지우면 복구할 수 없습니다.

## 로컬 실행

Node.js 22 이상:

```sh
npm install
npm run dev
```

Wrangler가 정적 자산을 준비하고 로컬 Workers/Durable Objects를 실행합니다. 정적 파일만 열면 온라인 기능과 게시판이 동작하지 않습니다.

- 이동: WASD / 방향키 / 드래그 조이스틱 (드래그 거리에 따른 속도 조절)
- 시점: 드래그, 휠 또는 두 손가락 확대/축소
- 기도: 기도 시작 후 다음 자세. 이동하려면 기도 마치기
- 언어 변경: 설정 → 언어 선택. 현재 화면에 즉시 적용되고 다음 접속에도 유지됩니다.

## Cloudflare 배포

이 저장소는 기존 Cloudflare Worker **allah**에 맞춰 설정되어 있습니다. `wrangler.jsonc`의 이름을 임의로 바꾸면 기존 GitHub 연결 배포가 실패할 수 있습니다.

- GitHub: `yonddu/Allah`, `main`
- Cloudflare: Workers 프로젝트. Pages 정적 프로젝트가 아님
- 빌드: `npm run check && npm test && npm run build`
- 배포: `npx wrangler deploy`
- 루트: `/`
- Durable Object: `ROOMS / PrayerRoom`, `COMMUNITY / Community`
- SQLite 스키마는 Community 클래스가 최초 실행 시 준비

대시보드에서 연결이 완료되면 main 커밋마다 검사/빌드 후 자동 배포합니다. API 토큰이나 계정 비밀은 저장소에 넣지 않습니다.

## 검증

```sh
npm run check
npm test
npm run build
npx wrangler deploy --dry-run
```

Node 내장 SQLite로 기기 쿠키·친구 수락·게시판 저장/삭제 권한·도배 제한을 검사합니다. 서버 채팅 필터·이동 제한·펜스 예외·방위각 테스트도 포함합니다. GitHub Actions는 검사와 Worker 패키징만 수행하며 Cloudflare 배포는 연결된 Workers Builds가 담당합니다.

## 한계와 다음 단계

건축물은 실제 장소에서 영감을 받은 가상 재구성입니다. 캐릭터는 제공된 정면 이미지를 입힌 18본 3D 모델로 옆면·뒷면은 근사 형태입니다. 실기기 성능 검수와 추가 리깅 개선은 필요합니다. 실시간 채팅은 저장하지 않습니다.

게시판·친구는 서버에 남지만 로그인 복구, 신고/관리자 도구, 운영용 접속 제한과 부하 검증은 다음 단계입니다. 낭송은 외부 스트리밍이므로 원본 가용성과 모바일 데이터 사용량에 영향을 받습니다. 자세한 다음 작업은 [인수인계](HANDOFF.md)를 참고하세요.

## 성능 기준과 시작 흐름
RAM 3~4GB의 보급형 Android, 720p~1080p 화면, 4G 환경을 기준으로 자동 모드 30fps를 목표로 합니다. 보급폰은 512~1K 텍스처와 경량 GLB를 사용합니다. 건축은 오프라인에서 재질별로 합쳐 생성하고, 화면 해상도·먼 캐릭터 디테일을 제한합니다. 실기기 FPS 보장은 아니며 기기별 검수가 필요합니다.

첫 방문은 언어 → 캐릭터·복장·양탄자 → 공간·서버 → 입장 순서입니다. 캐릭터 단계는 동일한 3D 캔버스를 옮겨 미리보기하므로 추가 WebGL 컨텍스트를 만들지 않습니다.

누르 기도원 건물은 보급폰용 약 2.4만 삼각형/7 draw calls, 상세 모델 약 3.8만 삼각형/7 draw calls입니다. 캐릭터를 포함한 최종 성능은 인원·기기에 따라 달라지며 실제 보급폰 검수가 필요합니다.


## 최신 기능

상단 시계 아이콘에서 위치 기반 하루 다섯 번 기도 시작 시각과 다음 기도까지 남은 시간을 확인할 수 있습니다. GPS 또는18개 도시/직접 좌표를 사용하며, 외부 서버에 좌표를 보내지 않습니다. 계산 방식·아스르 기준·이샤 보정·시간대를 선택할 수 있습니다. 현지 모스크 시간표를 확인하세요. 꾸란 읽기 버튼은 https://quran.com/ 을 새 창으로 엽니다.

두 맵은 각각3개 서버(서버당50명)를 제공합니다. 이전 방 선택은 새 맵으로 자동 이전됩니다. 캐릭터, 하단 전체채팅·귓속말·차단, 첫 방문 언어→꾸미기→입장 흐름을 유지합니다. 현재351개 문구를21개 언어로 지원합니다.
