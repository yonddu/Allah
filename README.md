# Allah · NOOR 온라인 기도원

개인 캐릭터와 양탄자를 꾸미고 세계의 모스크를 참고한 가상 공간에서 함께 머무는 3D 웹 메타버스입니다.

## 기능

- 얼굴형·피부 톤·수염·이름·기도 복장·머리 덮개·양탄자 문양/색상 선택, 이 기기에 자동 저장
- 고해상도 대리석 결, 양탄자 직조/자수, 브러시드 골드, 푸른 타일, 환경 반사와 품질 설정
- 셰이크 자이드 모스크 / 술탄 아흐메트 모스크 / 예언자 모스크에서 영감을 받은 가상 내부 공간
- 맵당 3개 서버, 서버당 32개 연결, 실제 WebSocket 이동·외형·기도 자세 동기화
- 위치/도시/좌표로 카바 방위각 계산, 지원 휴대폰의 절대 방향 센서 추적. 위치는 서버로 전송하지 않음
- 건의사항·자유게시판: 서버 영구 저장, 목록/페이지/상세/글쓰기/본인 글 삭제, 연속 게시 제한
- 기기별 친구 코드, 친구 요청/수락/거절/해제, 현재 서버 채팅
- 기도 자세 순환과 방향 정렬
- 기본 소리: 퍼블릭 도메인 물소리 + 바람/실내 룸톤. 악기 없음
- 기도모드: **2시간 25분 10초 알바카라 낭송** 개인 스트리밍/반복. 기도 종료 시 멈추고 다음 기도에서 이어 듣기. 기도 중 자연음 끄기. 음량/음소거/개인 음원 선택
- 낭송은 CC0로 표시된 원본을 사용. 전체 꾸란 녹음으로 표시하지 않음. [음원과 라이선스](CREDITS.md)

## 유료 기능 상태

유료 펜스의 서버 충돌 검사와 친구 입장 예외, 구독자의 친구 채팅 필터는 코드에 포함되어 있습니다. 유료 권한은 서버 DB의 `premium_until`로만 판단하며 클라이언트가 권한을 만들 수 없습니다.

**실제 결제 공급자와 결제 웹훅은 미연결 상태입니다.** 기본 사용자에게 유료 권한을 주지 않습니다. 무료 사용자의 펜스 버튼은 디자인만 보여주는 개인 미리보기이며 온라인 진입 제한이나 결제가 발생하지 않습니다.

결제 활성화 전에 정식 로그인·복구와 결제 공급자, 서명 검증 웹훅을 연결해야 합니다. 현재 기기 쿠키 기반 계정은 쿠키를 지우면 복구할 수 없습니다.

## 로컬 실행

Node.js 22 이상:

```sh
npm install
npm run dev
```

Wrangler가 정적 자산을 준비하고 로컬 Workers/Durable Objects를 실행합니다. 정적 파일만 열면 온라인 기능과 게시판이 동작하지 않습니다.

- 이동: WASD / 방향키 / 화면 이동 패드
- 시점: 드래그, 휠 또는 두 손가락 확대/축소
- 기도: 기도 시작 후 다음 자세. 이동하려면 기도 마치기
- 실제 메카 방향: 내 위치 사용 또는 도시/좌표 선택. 센서 미지원 시 북쪽 기준 방위각

## Cloudflare 배포

이 저장소는 기존 Cloudflare Worker **allah**에 맞춰 설정되어 있습니다. `wrangler.jsonc`의 이름을 임의로 바꾸면 기존 GitHub 연결 배포가 실패할 수 있습니다.

- GitHub: `yonddu/Allah`, `main`
- Cloudflare: Workers 프로젝트. Pages 정적 프로젝트가 아님
- 빌드: `npm run check && npm test && npm run build`
- 배포: `npx wrangler deploy`
- 루트: `/`
- Durable Object: `ROOMS / PrayerRoom`, `COMMUNITY / Community`
- SQLite 스키마는 Community 클래스가 최초 실행 시 준비

대시보드에서 연결이 완료되면 main 커밋마다 검사/빌드 후 자동 배포합니다. API 토큰이나 계정 비밀은 저장소에 넣지 않습니다.

## 검증

```sh
npm run check
npm test
npm run build
npx wrangler deploy --dry-run
```

Node 내장 SQLite로 기기 쿠키·친구 수락·게시판 저장/삭제 권한·도배 제한을 검사합니다. 서버 채팅 필터·이동 제한·펜스 예외·방위각 테스트도 포함합니다. GitHub Actions는 검사와 Worker 패키징만 수행하며 Cloudflare 배포는 연결된 Workers Builds가 담당합니다.

## 한계와 다음 단계

모스크 공간과 인물은 절차적으로 만든 초기 3D 모델이며 실제 건물의 정밀 복제물이 아닙니다. 정식 3D 캐릭터, 더 정교한 기도 동작, 모스크별 구조 확장과 실기기 검수가 필요합니다. 실시간 채팅은 저장하지 않습니다.

게시판·친구는 서버에 남지만 로그인 복구, 신고/관리자 도구, 운영용 접속 제한과 부하 검증은 다음 단계입니다. 낭송은 외부 스트리밍이므로 원본 가용성과 모바일 데이터 사용량에 영향을 받습니다. 자세한 다음 작업은 [인수인계](HANDOFF.md)를 참고하세요.
